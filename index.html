How this shelf works

No framework, no build step, no database. Three moving parts.

01

One line to add

A new build gets one entry in assets/js/projects.js — or just its GitHub URL. The card, title, tags and links build themselves.

02

Screenshots drop in

Save a shot as thumbnails/<repo-name>.png. If it's missing, the card falls back to that repo's GitHub preview image.

03

Live by default

If a repo has GitHub Pages switched on, a Play button appears on the card automatically — no extra bookkeeping.

That's the shelf.

New builds land here whenever they're worth showing. Bugs and ideas welcome.
